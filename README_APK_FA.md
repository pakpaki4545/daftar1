# پروژه اندروید دفتر نمره مهندس ایزانلو

این پوشه یک پوستهٔ اندرویدی WebView است که رابط فعلی دفتر نمره را از فایل‌های محلی اجرا می‌کند و لوگوی ارائه‌شده را دارد. انتخاب فایل برای بازیابی پشتیبان در WebView پشتیبانی شده است.

## ساخت APK در GitHub Actions
1. یک مخزن خصوصی در GitHub بسازید.
2. محتویات این پوشه را در مخزن بارگذاری کنید.
3. از زبانه Actions، کار `Build Android APK` را اجرا کنید.
4. پس از پایان موفق، در اجرای workflow بخش Artifacts، فایل `daftar-namre-debug-apk` را دریافت کنید.
5. APK را روی گوشی آزمایش کنید. این APK در صورت ساخت موفق، نسخه debug است و برای انتشار فروشگاهی به امضای release و آزمون‌های بیشتر نیاز دارد.

## محدودیت‌ها
- این محیط فاقد Android SDK و Gradle نصب‌شده است؛ بنابراین فایل APK در همین محیط ساخته و آزمایش نشده است.
- این بسته فعلاً داده‌ها را در localStorage همین نصب ذخیره می‌کند؛ همگام‌سازی Supabase، ورود امن مدیر/معلم و نقش‌ها فعال نشده‌اند.
- قفل برنامه فعلی یک رمز ساده در سطح رابط است، نه امنیت سیستمی/رمزگذاری داده‌ها.
- قبل از استفاده واقعی، روی دستگاه آزمایشی با داده‌های ساختگی تست کنید و از پشتیبان‌گیری اطمینان بگیرید.
